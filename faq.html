What is The Kollection?

The Kollection is a curated Nuvio collection setup built around organized catalogs and custom artwork. The current collection includes hundreds of catalogs covering Discover rows, streaming platforms, genres, studios, franchises, actors, directors, decades, awards and festivals, holidays, anime, and more.

What is the easiest way to set up The Kollection?

Use the Set Up Collection page. It walks you through connecting Nuvio, preparing AIOMetadata, optionally adding Bingecat, reviewing the setup, and installing the finished configuration.

What does AIOMetadata do for The Kollection?

AIOMetadata supplies the regular catalog sources used throughout The Kollection. The setup process creates or prepares the AIOMetadata configuration needed by the collection and connects those catalog sources to your Nuvio profile.

Which API keys do I need for AIOMetadata?

In the current Set Up Collection flow, an MDBList API key is required. A TMDB API key is optional and can improve metadata resolution. If you import your own custom AIOMetadata configuration, any additional credentials depend on the options you chose in that configuration.

Why can setup create more than one AIOMetadata configuration?

The Kollection can reference more catalogs than a single AIOMetadata host allows in one configuration. When needed, Set Up Collection automatically splits the required catalogs across multiple AIOMetadata configurations while keeping the collection connected to the correct sources.

Is Bingecat required?

No. Bingecat is optional. The rest of The Kollection can be used without it. Bingecat is specifically used for personalized recommendation catalogs in the For You area, such as recommended movies and recommended series.

Why does Bingecat need my own manifest URL?

Each Bingecat installation can have its own addon ID and catalog IDs. Set Up Collection reads your personal Bingecat manifest and replaces the collection's recommendation placeholders with the IDs from your configuration, so your For You rows point to your recommendations instead of somebody else's setup.

What happens if I skip Bingecat?

You can still install and use The Kollection. The Bingecat-powered recommendation rows will simply not be part of your personalized setup. Everything that uses the regular AIOMetadata catalog sources can remain available.

Can I install this cool collection without the set up guide?

Yes. If you prefer to set everything up manually, you can use the collection files and configuration resources available in The Kollection GitHub repository. The Set Up Collection guide is the easier option because it walks you through the required pieces and helps automate the setup, but it is not the only way to install the collection.

What is AIOStreams?

AIOStreams is a separate streaming-source addon that can combine multiple source addons and services into one unified stream list. It can deduplicate, filter, sort, and format results according to your configuration. It handles playback sources; it is separate from the collection and metadata catalogs supplied by The Kollection and AIOMetadata.

Do I need AIOStreams to use The Kollection?

No. AIOStreams is not required for the collection layout itself. You can add it separately if you want a unified way to manage the stream sources that appear when you choose a movie or series in Nuvio.

Can I use AIOStreams with Nuvio?

Yes. AIOStreams documents Nuvio as a compatible client. After configuring AIOStreams, you can use its generated manifest URL with a compatible client such as Nuvio. AIOStreams remains its own addon, so changing your stream setup does not require rebuilding The Kollection.

Will Set Up Collection remove my existing Nuvio collections?

The setup workflow is designed to preserve existing unrelated collections while it prepares and merges The Kollection into your Nuvio setup. Review the final step before installation so you can confirm what will be added.

Why are some catalogs or recommendation rows missing?

Start by checking the source that powers the missing row. Regular collection catalogs depend on the AIOMetadata configuration being installed and available to the same Nuvio profile. Personalized For You rows depend on the Bingecat manifest you supplied. AIOStreams affects stream results after you open a title, not whether The Kollection catalog rows appear.

Can I change my setup later?

Yes. AIOMetadata, Bingecat, and AIOStreams are separate configurations, so you can adjust them as your setup changes. For AIOStreams, most configuration changes can be saved without changing the installation URL; changes that alter the addon's manifest may require reinstalling or refreshing the addon in your client.

Where can I get help or report a problem?

You can use The Kollection's GitHub Discussions for questions and GitHub Issues for bugs. The site footer also links to the Nuvio Discord and Reddit community.
